How the live test works

This is a scripted sequence sent over Bluetooth, not an upload into the SP608E's firmware.

1. Set active outputs to Solid; move each color front-to-back using stepped fades.
2. Start the controller's Twinkling Stars effect briefly, in the selected color.
3. Return to solid, begin the next color, repeat until stopped.
Runs only while this page is open in Bluefy and Bluetooth is connected. No save-scene or firmware-upload commands are sent, but temporary output changes may affect power-on behavior. Recall your known saved scene after testing.
