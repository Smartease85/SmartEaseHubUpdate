# Native UX current-editor one-off Send

Text, Graffiti, Animation, Clock and Dynamic Text now expose their source one-off Send actions through a shared experimental owner admission. This is not local Save and does not change the stored library, Program selection or saved repeat. A transient captured current record sends once; the editor stays mounted through completion, Cancel and error. Existing controller ACKs do not prove display appearance or retention.

The current unsaved text input is synchronously validated/committed to the working draft before revision capture. Dynamic Text generates fresh post-GIF assets through the corrected common compiler under the captured draft guard; an old preview/prepared field is never authoritative. Current unsupported Dynamic backgrounds remain rejected. Clock transmits content only: there is no automatic or global time synchronization. Animation preserves existing raw/GIF ambiguity gates and exact speed domains.

Every owner send still needs fresh target, parked, original-app restore, overwrite and delayed-ACK confirmations. A single existing link-scoped lease covers notifications, writes, cancellation settlement and completion, shared with Program Send and the fixed orientation test. No transport starts when mounting, opening or compiling. No new controller/WeakMap or auto retry was added.

Monotonic editor revisions plus route/device/generation/characteristic checks reject late capture, late resource completion, edit→undo and stale callbacks. Back/route/hide/import/global backup revoke admission synchronously. Starting a new editor admission invalidates pending Native/full-backup import. Local mutation hooks are distinguished from hard owner cancellation during the synchronous preparation phase, and reentrant old intents cannot adopt newer cancellation/disposal.

Offline actual-index tests exercise all five kinds through the real compiler and a mock cached-ACK transport. No physical BLE or rendered iOS acceptance is claimed. Template/Material workflows and Clock Sync are separate remaining scope.

Review hardening: each explicit Save revokes Send before validation/resources/storage, including quota failure. Native import captures an explicit owner-intent serial before its own cancellation, verifies it survived reentrant callbacks, and only then captures its file-read epoch. Own Dynamic leave does not discard a valid import; any newer owner flow/hard leave still rejects the old file before reading or confirmation.
