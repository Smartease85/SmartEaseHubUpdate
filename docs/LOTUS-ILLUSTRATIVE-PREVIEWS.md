# Lotus effect illustrations

The 234 effect selections retain their existing controller IDs, category order, names and commands. The 33 built-in scene selections are unchanged.

The effect gallery uses independently authored geometric illustrations rather than original app GIFs. These are not firmware simulations or exact LED-output previews. For 209 effects, literal name cues inform representative colors, bands, dots, trails or opening/closing motion. The other 25 selections use static diagrams marked **Sequence unknown**. Duplicate labels share an illustration while retaining their distinct effect IDs.

Direction, geometry, timing, palette RGB values and speed relationships are not verified against the controller. Preview cadence is independent of the Speed control. Strobe-labelled effects use gentle illustrative pulses, not rapid flashing. A shared gallery legend and accessible tile descriptions disclose these limitations.

Preview motion can be paused. System reduced-motion preferences and hidden/offscreen views stop animation. Browsing, pausing, changing categories and loading illustrations never send device commands. The existing explicit Apply and parked-device consent gates remain unchanged.

All illustration code and geometry are newly authored for SmartEase. No original GIF frames, proprietary font resources, cloud credentials or remote asset downloads are used by this module.
