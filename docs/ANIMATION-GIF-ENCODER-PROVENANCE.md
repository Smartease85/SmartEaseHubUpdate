# Current GIF encoder provenance

The current Animation and Dynamic GIF encoders are rebuilt from pinned, licensed public gif.js and Glide sources with an independently authored bounded API adapter. See [the complete derivation and notices](GIF-ENCODER-LICENSED-REBASE.md) and `tools/licensed-gif-encoder/`.

The former implementation was based on static inspection of APK classes; its provenance and implementation remain only in the private historical reference archive. The new source basis does not retroactively license that historical implementation or any other original-app resources.
